# Carniflora Tower Offence

Web-based tower defense game built with HTML, CSS, and JavaScript for COMP-7082 course project.

## Game Concept

A reverse tower defense game where players use carniflora to defeat enemy towers. Players control a team of specialized carniflora to destroy defensive structures while managing resources and terrain.

## Features Implemented

### Core Systems
- Plant management with 8 unique carnivorous plant types
- Resource system (sun, minerals)
- Wave progression with increasing difficulty
- Grid-based plant placement
- Enemy AI with basic pathfinding
- State management

### Plant Types
1. **Trapping Plants**: Venus Flytrap, Pitcher Plant, Drosera, Sarracenia
2. **Shooting Plants**: Sundew, Utricularia, Rafflesia, Nepenthes  
3. **Manipulation Plants**: Special plants with unique environmental effects

### Game Mechanics
- Strategy-focused gameplay with resource management
- Environmental modification (simplified in this version)
- Progressive difficulty through waves
- Combat system with plant abilities
- Survival vs. defeat conditions

## Technical Architecture

### Files Structure
- `index.html` - Main game page  
- `css/style.css` - Game styling
- `js/main.js` - Core game logic
- `js/plant-system.js` - Plant management system  
- `js/enemy-system.js` - Enemy behavior
- `js/resource-system.js` - Resource handling
- `js/wave-system.js` - Wave progression

### Technologies Used
- HTML5 for structure and layout
- CSS3 for styling and responsive design  
- JavaScript ES6+ for game logic
- No external libraries or frameworks (pure vanilla JS)

## How to Play

1. Open `index.html` in a web browser
2. Select a plant from the sidebar
3. Click on grid cells to place plants
4. Press "Start Game" to begin
5. Waves of enemies will spawn automatically
6. Manage resources and strategic placement for victory
